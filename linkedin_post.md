# LinkedIn Post for Task 4

🚀 **Task 4 Completed! Built a Minimalist, Keyboard-First Task Manager** 📋⚡

For the 4th task of my **Skillcraft Web Development Internship**, I wanted to build something beyond a typical to-do list. Inspired by modern developer-first productivity tools like **Linear**, **Notion**, and **Things3**, I engineered **Sleek Task Manager** from the ground up!

Instead of bulky modals or clunky forms, the app is designed for blazing-fast workflow speed:

✨ **What I built:**
🔹 **Natural Language Input Engine**: Type directly like a power user — `Finish project report tomorrow 5pm !high @coding` — and the custom regex parser instantly detects dates, exact times, priority tags, and project categories.
🔹 **Zero-Dependency Native Architecture**: Built with pure HTML5, vanilla modern CSS, and ES6+ JavaScript. No bloated npm libraries, zero third-party script lag.
🔹 **Linear-Inspired Aesthetic**: High-contrast, clean white theme with crisp Emerald Green accents, custom rounded checkboxes with smooth check animations, and status pills.
🔹 **Keyboard-First Navigation**: Full keyboard shortcuts (`N` for new task, `/` to search, `Esc` to cancel or dismiss) so you never have to leave the keyboard.
🔹 **Real-time Search & Instant Sorting**: Filter by *Pending* or *Completed*, and sort dynamically by priority level, newest/oldest, or due date.
🔹 **Persistent Local Storage**: Offline-capable and automatically synchronized so your daily agenda is always ready.
